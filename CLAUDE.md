# Hinweise für KI-Agenten

**Vor jeder Aufgabe:** [claude/context.md](claude/context.md) lesen – Projektkontext, Arbeitsregeln und Übersicht aller
Features. Für Arbeiten an einem Feature zusätzlich die passende Datei unter [claude/features/](claude/features/) lesen.

**Nach jeder Änderung den Kontext aktuell halten** (gehört zur Aufgabe, nicht optional):

- Feature geändert → die zugehörige Datei unter `claude/features/` anpassen (Verhalten, wichtige Dateien, Entscheidungen,
  offene Punkte).
- Neues Feature → neue Datei `claude/features/<name>.md` im selben Aufbau anlegen und in der Tabelle in
  `claude/context.md` verlinken.
- Neue Arbeitsregel, Entscheidung mit Tragweite oder Architekturänderung → in `claude/context.md` ergänzen.
- Offene Punkte für den Go-live → zusätzlich in der [README](README.md#vor-dem-go-live) unter „Vor dem Go-live“.
- Veraltetes löschen statt stehen lassen; Links auf Dateien relativ halten und prüfen, dass sie existieren.
